# 🚨 ABEP – Afet Bilinçlendirme ve Eğitim Platformu

ABEP, vatandaşları doğal ve insan kaynaklı afetler konusunda bilinçlendirmek ve eğitmek amacıyla geliştirilmiş bir web platformudur. Kullanıcılar; deprem, sel, yangın, heyelan gibi afet türleri hakkında **öncesinde**, **anında** ve **sonrasında** ne yapmaları gerektiğine dair kapsamlı bilgilere bu platform üzerinden ulaşabilir.

---

## 🌍 Proje Amacı

Türkiye, deprem başta olmak üzere pek çok afet riski taşıyan bir coğrafyada yer almaktadır. Yaşanan afetlerde can kayıplarının önemli bir kısmı, bilinçsizlik ve hazırlıksızlıktan kaynaklanmaktadır. ABEP bu boşluğu doldurmak için:

- Her afet türüne özel **hazırlık, müdahale ve toparlanma** bilgileri sunar
- Kullanıcılara **bilinçlendirici ve eğitici içerikler** sağlar
- Afet farkındalığını artırmayı hedefleyen **sade ve erişilebilir** bir arayüz sunar

---

## ⚙️ Özellikler

### 👥 Kullanıcı Tarafı
- Afet türlerine göre kategorize edilmiş bilgi sayfaları
- Her afetle ilgili detaylı içerikler (önce / sırasında / sonra)
- Kayıt ve giriş sistemi

### 🛠️ Admin Paneli
- Kullanıcı yönetimi (listeleme, düzenleme, silme)
- Rol tabanlı yetkilendirme sistemi
- Afet ekleme ve düzenleme
- Afete özel detay bilgisi ekleme / güncelleme
- İçerik yönetimi

---

## 🧰 Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|---|---|
| ASP.NET Core MVC | Web uygulama çatısı |
| ASP.NET Core Identity | Kimlik doğrulama ve yetkilendirme |
| C# | Backend programlama dili |
| HTML5 / CSS3 | Sayfa yapısı ve stil |
| Bootstrap | Responsive arayüz tasarımı |
| JavaScript | İstemci tarafı etkileşimler |
| Entity Framework Core | Veritabanı işlemleri (ORM) |
